# IDRA Day 7 - Dataset Summary Report

## Assignment

Dataset Summary Report using Python and Pandas.

## Organization

India Data Research Academy (IDRA)

## Description

This project explores a Student Dataset using Python and Pandas.

The notebook demonstrates how to inspect the basic structure of a dataset and generate descriptive statistics.

## Analysis Performed

- Loaded CSV dataset
- Displayed first few rows
- Displayed last few rows
- Displayed random samples
- Checked dataset shape
- Checked column names
- Checked index
- Checked data types
- Used info()
- Used describe()
- Checked missing values
- Checked duplicate records
- Added basic observations
- Added conclusion

## Dataset Details

The dataset contains 25 rows and 7 columns.

The main features are:

- Student_ID
- Name
- Age
- Course
- Marks
- Attendance_Percentage
- City

## Python Library Used

- Pandas

## Conclusion

The project demonstrates how Pandas can be used to understand the structure, data types, descriptive statistics, missing values and basic characteristics of a dataset.
